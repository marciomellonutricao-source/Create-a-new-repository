# Marcio Mello — Nutrição Esportiva e Saúde

Site institucional responsivo para apresentação dos atendimentos de Marcio Mello, Nutricionista Esportivo e Clínico (CRN 48045/P).

## Estrutura
- `index.html`: conteúdo e seções do site
- `styles.css`: identidade visual e layout responsivo
- `script.js`: menu mobile e comportamento do botão de contato
- `logo.svg`: versão vetorial da marca para uso no cabeçalho

## Configuração pendente
No arquivo `script.js`, preencha `WHATSAPP_NUMBER` com o número profissional em formato internacional, apenas números (ex.: `5587999999999`).

## Publicação
O projeto é estático e pode ser publicado pelo GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
